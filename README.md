# 모닝 브리핑 (Android)

정해진 시간에 오늘 날씨와 주요 뉴스 헤드라인을 한국어 음성으로 읽어주는 안드로이드 앱입니다.

## 기능
- 매일(또는 평일만) 원하는 시각에 자동으로 브리핑 시작
- 날씨: 현재 날씨·기온·체감 온도, 오늘 최고/최저, 강수 확률, 우산·옷차림 한마디 (Open-Meteo, API 키 불필요)
- 뉴스: 구글 뉴스 한국판 주요 헤드라인 3 / 5 / 10개
- 날씨 지역: 도시 이름 검색 또는 현재 위치 (기본값 서울)
- 말하기 속도 조절, "지금 들어보기" / "멈추기", 알림창에서도 멈추기 가능
- 휴대폰 재부팅 후에도 알람 자동 복구
- 알람 볼륨으로 읽어서 미디어 볼륨이 0이어도 들림

## APK 만들기

### 방법 1: GitHub에서 자동 빌드 (PC에 아무것도 설치 안 해도 됨)
1. GitHub에 새 저장소를 만들고 이 폴더 전체를 올립니다.
2. 저장소의 **Actions** 탭 → **Build APK** 실행이 끝나면 (약 3~5분)
3. 실행 결과 페이지 아래 **Artifacts** 에서 `MorningBrief-apk` 를 내려받아 압축을 풀면 `app-debug.apk` 가 나옵니다.

### 방법 2: Android Studio
1. Android Studio에서 **Open** → 이 폴더 선택
2. 동기화가 끝나면 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
3. 휴대폰을 USB로 연결했다면 ▶ 실행 버튼으로 바로 설치

## 휴대폰에 설치 후 설정
1. APK를 휴대폰으로 옮겨 실행 → "출처를 알 수 없는 앱 설치" 허용
2. 앱을 열고 알림 권한 허용
3. 시간을 눌러 기상 시각 설정 → 스위치 켜기
4. **지금 들어보기**로 한 번 테스트
5. 소리가 안 나거나 영어 발음으로 읽으면: "음성(TTS) 엔진 설정 열기"에서 Google 음성 엔진(또는 삼성 TTS)의 **한국어 음성 데이터**를 설치하세요.
6. (권장) 설정 → 애플리케이션 → 모닝 브리핑 → 배터리 → **제한 없음**. 삼성/샤오미 등은 절전 설정 때문에 알람이 늦을 수 있습니다.

## 구조
```
app/src/main/java/com/morningbrief/
  MainActivity.kt     설정 화면
  AlarmScheduler.kt   매일 알람 예약 (setAlarmClock)
  AlarmReceiver.kt    알람 수신, 재부팅 시 재예약
  BriefingService.kt  뉴스·날씨 받아서 TTS로 읽는 포그라운드 서비스
  Briefing.kt         뉴스(RSS)/날씨(Open-Meteo) 가져오기, 읽을 원고 만들기
  Prefs.kt            설정 저장
```
외부 라이브러리 없이 Android 기본 API만 사용합니다. 최소 Android 8.0 (API 26).
